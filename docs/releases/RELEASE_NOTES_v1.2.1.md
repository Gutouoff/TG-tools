# TG工具箱 v1.2.1

> 修复版：修掉「拖入压缩包导入账号失败」。遇到问题请把程序 `logs` 目录最新日志发给开发者。

## 更新内容（相对 1.2.0）

### 修复

- **拖入 zip 导入账号失败**：压缩包里账号数据外面多套了一层（或多层）文件夹时（如 `xxx.zip → 账号名 → session/json/tdata`），会报「未识别到账号数据（需要 .session、tdata 或其压缩包）」。原因是账号识别只看了「解压目录 + 一层子目录」，而拖入比「导入」按钮多解压一层。现在会逐层往下找（最多 3 层，并跳过 macOS 压缩包里的 `__MACOSX` 等杂物目录）
- **同时含 session 与 tdata 的包被误判成 tdata**：这种包走「导入」按钮时会额外触发一次 tdata→session 转换，按文件夹名另写一个 session 和 json，等于凭空多出一条登录态。现在包内有 `.session` 就按 session 账号处理，不再转换

### 说明

- 账号文件夹名规则不变：有 session 用 session 文件名，tdata 包沿用 zip 名
- 本次只改导入识别逻辑，界面与既有功能无变化

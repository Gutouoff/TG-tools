# TG工具箱 v1.2.3

> 界面重构版：整站换成清爽的蓝色主题，设置页改为左侧分区导航，会话区补齐刷新与键盘操作。功能与数据格式不变，旧配置自动迁移。遇到问题请把程序 `logs` 目录最新日志发给开发者。

## 更新内容（相对 1.2.2）

### 界面：全新蓝色主题

- 主色由青绿换成 `#356AE6`，重做中性色阶、字体层级、圆角与阴影；浅色/深色两种模式同步调整。
- 旧版青绿配色的设置会在启动时自动迁移为蓝色主题；自己选过其他预设色的不受影响。

### 界面：设置页重构

- 设置改为**左侧分区导航**（通用 / 外观 / 代理 / 加群频道 / 白名单 / 关于），每个分区带标题与一句话说明。
- 外观页色板补上新主色，当前主题能正确显示选中状态（以前会显示成「自定义」）。

### 界面：会话区

- 会话列表新增「刷新」按钮，加载中用「加载中…」占位，历史为空时显示「暂无消息」。
- 会话条目支持键盘操作（回车/空格打开），补齐读屏用的无障碍标签。
- 聊天面板排版与长文本换行调整，深色模式下对比度更好。

### 其他

- 后端默认主题值同步为新蓝色（仅影响新安装；已有 settings.json 不会被改写）。
- 导出 `账号总表.xlsx` 的表头配色跟随新主题。
- `cable`（passkey）模块改为按需加载：运行环境缺可选依赖时，passkey 接口返回明确提示，不再导致整个服务导入失败。

### 说明

- 本次没有删除或改动任何账号操作逻辑，账号目录结构不变
- 本次为微调号 1.2.3，配置结构无破坏性变更，可随时退回 1.2.2

# TG工具箱 v1.2.0

> 新功能版本：全新「新建账号」入口（三种登录方式）。遇到问题请把程序 `logs` 目录最新日志发给开发者。

## 更新内容（相对 1.1.1）

### 新功能：新建账号（顶栏按钮）

三种方式，成功后自动创建完整账号（session + json + Telegram.exe）：

- **拖入文件**：支持 `.session` / `.json` / `2fa.txt` / `.zip`；zip 自动解压（含 tdata 包，自动转换为 session）
- **扫码登录**：手机 Telegram → 设置 → 设备 → 链接桌面设备，扫码确认即登录（约 30 秒有效期，与官方一致）
- **手机号登录**：输入手机号收验证码；开启两步验证的账号自动进入 2FA 密码步骤

### 账号导入增强

- 拖入 zip 创建账号时，默认用 **session 文件名**作为账号文件夹名（tdata 包沿用 zip 名）
- 仅 session 的账号在导入/创建时**立即自动补建凭据 json**（不再等首次连接）

### 界面

- **加群频道页一体化**：链接的添加/编辑/删除/加入全部在右栏页面完成（入口移至「其他设置」卡）
- 打包结果**直接进剪贴板**，不再留在账号根目录（暂存 %TEMP%，超过一天自动清理）
- 界面与日志文案全面书面化精简

### 安全加固

- 首页访问必须携带 token（防止本机恶意进程扫描端口窃取控制权）
- Host 白名单校验（防 DNS rebinding 攻击）

### 修复

- 分组拖动排序（重写为指针拖动，真浏览器双向验证通过）
- 程序冷启动时 `/api/online` 500
- 64 位下剪贴板句柄截断导致的复制失败
- 老版本升级后「转换」卡片不显示、批量任务可并发冲突等多项隐患

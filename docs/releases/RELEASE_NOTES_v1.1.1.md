# TG工具箱 v1.1.1

> 维护版本：新功能增强 + 代码审查修复。遇到问题请把程序 `logs` 目录最新日志发给开发者。

## 更新内容（相对 1.1.0）

### 功能增强
- **邮箱登录**：绑定成功后显示已绑邮箱（本地持久化，点「换绑邮箱」可更换）；新增**预选邮箱**——在「设置 → 加群频道」栏目维护常用邮箱，绑定页一键填入
- **通行密钥**：扫码等待时长延长至 **5 分钟**；等待期间进度条每 10 秒心跳反馈（不再干等无响应）
- **分组**：拖动排序改为更可靠的指针实现（按住标签拖到目标上松手即落位）；**记忆上次所在分组**，重启自动恢复

### 修复（代码审查发现）
- 老版本升级后**「转换」卡片不显示**：settings 里的旧卡片顺序缺新卡片，现已迁移时自动补齐
- **批量任务并发冲突**：删联系人 / 删对话 / 加群 / 批量刷新 session 此前不检查任务互斥，可同时触发导致取消标志互相干扰；现统一互斥，并发触发提示「已有任务在运行」
- **账号轮询完成后死号标识偶发不刷新**：完成检测不再依赖日志文案，改用结构化事件标记

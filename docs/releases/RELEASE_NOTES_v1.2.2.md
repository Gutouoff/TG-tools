# TG工具箱 v1.2.2

> 修复版：重命名账号文件夹不再因「文件夹被占用」直接失败，改为排队等占用解除后自动改名。遇到问题请把程序 `logs` 目录最新日志发给开发者。

## 更新内容（相对 1.2.1）

### 修复：重命名账号文件夹遇占用直接失败

- 用「启动客户端」打开的 Telegram.exe 还占着账号文件夹时，改名会报 `重命名失败: [WinError 5] 拒绝访问…（若刚用过「启动客户端」,请先关闭该客户端）`。
  现在这种情况不再报错，而是**加入「待执行」**：账号列表上出现青色的 **`待改名`** 徽标（悬停显示目标名），
  后台每 10 秒试一次，**该账号客户端一关掉、占用一解除就自动改名**，改完列表与徽标自动刷新，日志说明结果。
- 右键账号新增 **「立即执行待改名 → 新名」** 与 **「取消待改名」**：可以不等后台周期手动触发，也可以放弃这次排队。
- 排队改名的效果与直接改名一致：分组、资料缓存、头像文件名一并同步改名；
  待执行条目最长保留 3 天，超时放弃并在日志里说明。

### 说明

- 只改了重命名流程，其他功能与界面无变化
- 新增运行时文件 `rename_pending.json`（存放待执行改名，只含文件夹名，不含任何账号凭据）

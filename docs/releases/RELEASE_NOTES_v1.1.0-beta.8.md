# TG工具箱 v1.1.0-beta.8

> 测试版（beta）。遇到问题请把程序 `logs` 目录最新日志发给开发者。

## 更新内容（相对 beta.7）

### 修复
- **格式转换报 Internal Server Error / JSON 解析失败**：服务器未捕获异常现在一律返回 JSON 错误信息（不再返回纯文本 500 导致前端二次报错）；转换流程中的账号问题会显示明确的中文原因（如缺少凭据 json、tdata 已存在等）
- **按钮风格不统一**：中栏所有操作按钮统一为描边样式，仅「删除账号」保留红色危险样式
- **连接/切换账号后右栏停留上一个账号的视图**：自动回到日志页
- **刷新 session 命名**：转换后保持账号原有 session/json 文件名，不再产生多余的 json 文件（此前会导致「找到多个 json」）

### 功能调整
- 「更新本体」更名 **「安装升级客户端」** 并增强：更新完成后会给**没有客户端的账号文件夹**自动补装 Telegram.exe/Updater.exe（下载 → zip 校验 → 代码签名校验通过后才落盘）
- **搜索增强**：@ 前缀忽略；纯数字关键词可直接匹配手机号/用户ID（免输区号）
- **重命名弹窗快捷填充**：姓名 / username / 手机号 / 用户 ID 一键填入；可在「设置 → 通用」里开关各项并配置自定义前缀

## 附件

- `TG-tools_v1.1.0-beta.8.zip`（约 29 MB）：解压后双击 `TG工具箱Web.exe`；首次启动 SmartScreen 拦截时选「更多信息 → 仍要运行」
- 此前修复继续有效：启动白屏自动降浏览器模式（beta.4）、tdata 转换缺文件（beta.5）、channel 构造体补丁（beta.6）

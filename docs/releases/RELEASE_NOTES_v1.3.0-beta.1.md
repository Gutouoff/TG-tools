# TG工具箱 v1.3.0-beta.1

> 预发布：新功能「Bot 收件箱」——把账号文件转发给自己的 TG bot，自动识别归档进账号列表。beta 期间请实测反馈；遇到问题请把程序 `logs` 目录最新日志发给开发者。

## 更新内容（相对 1.2.0）

### 新功能：Bot 收件箱（设置 → 🤖 Bot收件箱）

本地运行一个 TG Bot 接收器，人在手机/其他电脑上也能把账号文件送进工具箱：

- **用法**：@BotFather 免费创建 bot 拿到 token → 填入设置并启动 → 把账号文件（`.session` / 凭据 `.json` / tdata 或 session 的 zip / `2fa.txt`）直接转发给 bot，自动识别、建文件夹归档，结果回发到聊天里
- **多文件合并**：一次多选转发自动合并成一个账号；每个 zip 单独成一个账号
- **加密账号包**：zip 密码写在转发的文字说明里即可（或用「通用 → 默认压缩密码」），自动用 7-Zip 解密
- **安全**：只有「允许的用户 ID」列表内的人推送的文件才会被接收；其他人发消息只会收到他自己的 ID（方便把自己加进列表）；允许列表保存后即时生效
- **开机自启**：勾选「启动程序时自动运行」后，工具箱启动即拉起 bot
- 代理沿用工具箱代理设置；仅 session 的文件自动补建凭据 json、tdata 自动转 session（与拖放新建账号同一套逻辑）

### 其他

- 拖放新建账号同样获得加密 zip（7z AES）解压支持（与 Bot 收件箱共用归档逻辑）
